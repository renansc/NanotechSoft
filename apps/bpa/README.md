# BPA

Interface do catálogo global Nanotech para prontuário ambulatorial e exploração
de tabelas BPA. O frontend fica em `apps/bpa/source` e é servido pelo Portal.

O módulo é obrigatório no perfil `nanotech` e permanece desabilitado nos
clientes que não o contrataram. Configurações locais e dados de prontuário não
devem ser gravados no repositório.
