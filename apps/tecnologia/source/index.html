Rede e dispositivos

SNMP

Use SNMP somente leitura para roteadores, switches, NVRs e impressoras. O módulo coleta identificação, CPU quando disponível e tráfego das interfaces.

  1. Ative SNMP no equipamento.
  2. Restrinja o acesso ao servidor 192.168.200.254.
  3. Edite o equipamento, escolha SNMP e informe a comunidade.

SNMP v2c não criptografa a comunidade. Prefira uma comunidade exclusiva e somente leitura; suporte a SNMPv3 fica indicado como próxima evolução.

Linux

Node Exporter

Para Ubuntu/Linux, o exporter Prometheus entrega CPU, memória, discos e rede sem criar login próprio no portal.

node_exporter --web.listen-address=:9100

Cadastre a sonda Prometheus exporter, porta 9100 e caminho /metrics.

Windows

Windows Exporter

Para Windows, instale o windows_exporter como serviço e libere a porta apenas para o servidor de monitoramento.

msiexec /i windows_exporter.msi ENABLED_COLLECTORS=cpu,cs,logical_disk,memory,net,os

Cadastre a sonda Prometheus exporter, normalmente na porta 9182.

Inventário

GLPI Agent

O GLPI Agent é a opção indicada para inventário de hardware, programas instalados, número de série e ativos. Ele complementa o monitoramento; exige uma instância GLPI para receber os inventários.

Zabbix Agent também é compatível como estratégia futura, mas nesta etapa o formato aberto Prometheus evita instalar um servidor Zabbix separado.
